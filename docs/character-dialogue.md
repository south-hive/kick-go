# 캐릭터 대사 조사 및 이벤트 배치

## 나루토

조사일: 2026-09-16. 공식 소개와 생일 기획에서 인정받으려는 열정, 포기하지 않는 성격, 그림자 분신과 나선환을 확인했다.

- 공식 작품 소개: https://naruto-official.com/en/about
- 공식 나루토 생일 기획: https://naruto-official.com/en/news/01_1610
- 공식 나선환 설명: https://naruto-official.com/en/news/01_1802

아래 문장은 게임 상황에 맞춰 새로 쓴 대사이며, 파쇄에는 사용자가 요청한 인터넷 나루토 밈 문구를 적용했다. 원작 또는 한국어 공식 더빙의 정확한 인용으로 표시하지 않는다. 대사와 연출만 바꾸며 물리 규칙이나 능력치는 바꾸지 않는다.

파쇄 문구는 읽을 시간을 확보하도록 1.8초 동안 표시하며, 기존 파란색 링 연출을 유지한다.

다중 아웃이 확정된 샷에서 탈락 대상과 처음 충돌할 때 숫자를 누적 표시한다. 기본과 나루토는 대사 정의의 `presentation: silent`로 숫자만 유지한다. 종료 요약 이벤트는 침묵하며 ‘막타’는 추가하지 않는다. 현재 훅은 금강불괴를 사전에 알았는지까지 판정하지 않으므로 iron:hit 대사는 방어에 막힌 상황 전체에 적용된다.

## 쿠루삥삥

사용자가 ‘약오르주, 못때리주라고 말하는 인터넷 밈의 초딩’이라고 설명했다. 게임 표시 이름은 요청한 ‘쿠루삥삥’을 유지한다. 특정 실존 아동이나 원작 인물로 단정하지 않고, 쿠쿠루삥뽕·어쩔티비 계열의 장난스러운 약 올리기 말투를 쓰는 게임 페르소나로 구현했다.

조사 근거:

- 타입캐스트의 쿠쿠루삥뽕/찬구 TTS 유래 설명: https://typecast.ai/kr/learn/how-to-make-changu-voice-twitch/
- 중앙일보 트렌드 사전의 약 올리기 용례: https://v.daum.net/v/20220217002633444

유행어의 말투를 참고했으며 아래 상황별 문장은 게임용으로 새로 구성했다. 특정 영상의 정확한 대사 인용이나 음성 재현이 아니다.

공격자와 방어자의 반응은 각자의 선택 캐릭터에 따라 독립적으로 발생한다. 파쇄에는 보라색 링과 외침, 겁쟁이에는 기존 안내 연출을 연결했다. 연속 내보내기는 타수별 전용 대사를 즉시 갱신하고 별도로 1타·2타·3타 숫자를 누적 표시하며 ‘막타’는 넣지 않는다. 캐릭터는 대사와 연출만 변경한다.

## 일괄 관리와 표시 계약

- `web/character-dialogue.js`: 모든 캐릭터의 상황별 대사 배열, 타수별 대사, 효과, 표시 시간 및 표시 정책을 관리한다. HTML과 서버가 같은 데이터를 읽는다.
- `web/characters.js`: 발화자·상대 역할과 타수에 따라 대사를 선택한다. 같은 이벤트는 모든 클라이언트에서 같은 대사로 해석된다.
- `web/shot-effects.js`: 선택된 반응의 표시 정책을 따른다. 이벤트 종류만 보고 대사를 무조건 버리는 예외는 없다.
- `queue`: 일반 대사는 순서대로 표시한다. `latest`: 해당 상황의 이전 단계를 새 단계로 즉시 교체한다. `silent`: 의도적으로 대사를 표시하지 않는다.
- 다중 아웃의 공통 숫자 HUD는 캐릭터 대사와 독립적이다. 기본·나루토의 기존 숫자 전용 표현은 그대로 유지하고, 쿠루삥삥은 등록된 전용 대사를 함께 표시한다.
- `tests/shot-effects.test.js`는 모든 등록 대사와 타수 배열을 양쪽 좌석에서 실제 표시 코드에 전달해 누락을 검사한다. 물리 규칙과 다중 아웃 대상 선정은 바꾸지 않는다.

현재 의도적 공백/검토 대상: 기본의 일반 아웃·방어 성공 대사 없음(기존 유지), 나루토의 방어 성공 대사 없음(후보만 조사), 모든 캐릭터의 종료 요약 대사 없음(중복 방지). 새 캐릭터나 대사는 이 목록과 함께 검토한다.

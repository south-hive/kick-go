# 틈의 오락실 — 알까기·비행·로봇·배틀십

플레이 주소: https://south-hive.github.io/kick-go/

`main` 브랜치에 올리면 GitHub Actions가 물리·온라인 통신·브라우저 테스트를 실행한 뒤 `web` 폴더를 GitHub Pages에 배포합니다. 혼자 하기와 한 기기 둘이 하기는 별도 서버가 필요하지 않습니다. **서로 다른 기기의 온라인 대전에는 Node.js 서버가 필요합니다.**

시작 화면에서 **나무 위의 한 수(알까기)**, **회색갈기의 비상(비행 팬 게임)**, **코드 아레나(로봇 규칙 대전)**, **깊은 바다의 한 수(온라인 배틀십)**를 선택합니다. 알까기의 기존 혼자·한 기기 둘이·온라인 모드를 유지하며, 예전 `/#room=...` 초대 링크도 알까기로 연결합니다. 비행 게임은 서버 없이 실행되고 프로젝트에 포함된 생성 이미지와 시스템 폰트를 사용합니다.

## 릴리즈 표시

게임 선택과 네 게임 화면 하단에 버전을 표시합니다. 현재 릴리즈는 `v1.5.0`이며 GitHub Pages 배포 시 `v1.5.0 · 커밋7자리 · 배포 실행번호.재시도번호`로 자동 표시됩니다. 배포마다 JS/CSS URL에도 같은 식별자를 넣어 이전 파일의 캐시와 구분합니다. 로컬 파일은 `v1.5.0 · 로컬`로 표시합니다. 버전을 올릴 때는 `package.json`과 `package-lock.json`을 함께 갱신하고 `npm run build:release`를 실행합니다.

## 실행

Node.js 20 이상이 설치된 환경에서 `npm ci` 후 `npm start`를 실행하고 `http://localhost:8080`에 접속합니다. 같은 Wi-Fi에 연결된 휴대폰에서는 실행 컴퓨터의 IP와 8080 포트로 접속할 수 있습니다. `web/index.html`을 직접 열면 오프라인 모드를 실행할 수 있습니다.

## 깊은 바다의 한 수 — 온라인 배틀십

`battleship.html`에서 별명(선택)을 입력하고 방을 만들거나 초대 코드로 입장합니다. **로비 → 함선 배치 → 교전 → 결과** 순으로 진행합니다. 온라인 서버는 기존 `KICK_GO_SERVER`를 사용하며 배틀십 전용 `/ws/naval`에 연결합니다.

- 두 함장 모두 위에 상대 해역, 아래에 자기 해역을 봅니다. 10×10 해역에 항공모함(5), 전함(4), 순양함(3), 잠수함(3), 구축함(2)을 배치합니다. 함선 선택 → 가로/세로 선택 → 아래 해역의 시작 칸 클릭으로 배치하며 자동 배치·철수·초기화도 지원합니다. 함선은 맞닿을 수 있지만 겹치거나 해역 밖으로 나갈 수 없습니다.
- 두 함장이 배치를 확정하면 교전을 시작합니다. 한 발마다 차례를 넘기며 상대 함선 5척을 전부 격침하면 승리합니다. 빗나감 물보라·명중 폭발·격침 효과, 선택 효과음을 제공합니다. 효과음은 기본 꺼짐입니다.
- 초대받은 사람은 관전 입장도 선택할 수 있습니다(최대 20명). 배치 중에는 안내만 표시합니다. 교전 중에는 양쪽 사격 결과와 격침된 함선만 보여주고 미발견 함선은 숨깁니다. 관전자에게는 참가자 1이 아래, 참가자 2가 위에 표시됩니다. 종료 후에는 전체 함선을 공개합니다.
- 서버가 배치·차례·중복 공격·명중·승패를 검증하며, 상대의 미공개 함선 좌표와 재접속 토큰을 다른 참가자나 관전자에게 보내지 않습니다. 관전 연결에서는 공격·배치·재대결 명령을 거부합니다.
- 같은 탭의 새로고침/재접속으로 자리·배치·교전을 복구합니다. 확정 전 배치 초안은 sessionStorage에 저장합니다. 두 함장이 재대결에 동의하면 배치를 새로 시작하고 선공을 교대합니다. 관전자는 그대로 다음 경기를 봅니다.
- 함장이 명시적으로 나가면 방 전체가 종료됩니다. 관전자 퇴장은 경기와 무관합니다. 서버 재시작, 10분 이상 연결 단절, 30분간 무활동 시 방이 종료됩니다. 서버 인스턴스 한 개에서 최대 100개 배틀십 방을 유지합니다.

## 코드 아레나

`robots.html`에서 로봇의 행동 규칙을 작성해 연습하거나, 한 기기에서 2~4대의 로봇을 자동 대전시킵니다. 각자 자기 PC의 연습장에서 스크립트를 다듬고 메신저로 전달한 뒤, 대전용 PC의 슬롯에 붙여넣으세요. 별도 파일·계정·온라인 서버·AI가 필요하지 않습니다. 연습용 코드와 대전 슬롯은 `code-arena:v1`에 자동 저장됩니다.

```text
탄환거리 < 90 : 방어, 후진(60)
적거리 > 230 : 추적, 전진(70), 공격
항상 : 회전(35), 전진(30), 공격
```

- 공백·줄바꿈 제외 500자, 최대 32개 규칙. 0.1초마다 위에서 처음 조건이 맞는 줄을 실행하고, 쉼표로 연결한 행동은 동시에 적용합니다. 맞는 조건이 없으면 정지합니다.
- 센서: 체력, 에너지, 적거리, 적각도, 벽거리, 탄환거리, 시간. 비교: `< > <= >= == !=`. 조건 없이 실행하려면 `항상`을 씁니다.
- 행동: 전진/후진(0~100), 회전(-180~180°/초), 추적, 정지, 공격, 방어. 포탑은 가장 가까운 적을 자동 조준합니다. 공격·방어 동시 사용은 불가합니다.
- 체력/에너지 100, 공격 피해 12·에너지 8·재장전 0.55초. 방어는 초당 에너지 24를 사용해 피해를 3으로 줄입니다. 비방어 상태에서는 에너지가 초당 12 회복됩니다.
- 전투는 고정 60Hz이며, 같은 스크립트·슬롯 순서·배치 번호면 재생 속도와 무관하게 동일한 결과가 나옵니다. 양쪽이 같은 틱에 전멸하면 무승부입니다.
- 연습 상대 4종, 선택식 규칙 추가, 오류 행·문자 수·현재 실행 규칙 표시, 0.5~4배 보기, 일시정지, 수정 후 재시작을 지원합니다. 다른 탭으로 이동하면 자동 일시정지합니다.
- 45초부터 안전 구역이 줄어들며 외부에서는 초당 체력 20이 감소합니다. 마지막 생존자가 승리합니다. 90초가 되면 남은 체력, 준 피해 순으로 승패를 정하고 둘 다 같으면 무승부입니다.
- 스크립트는 허용된 명령어만 해석합니다. JavaScript 실행, 반복문, 변수, 자유 문장, 네트워크 호출은 지원하지 않습니다. 전투가 시작되면 편집은 잠깁니다.

## 회색갈기의 비상

`flight.html`에서 클리프 또는 데미안을 선택해 240m 높이에서 도약시키고 하강 가속과 상승을 조절해 **5,000m 여정**을 완주하는 거리 게임입니다. 헤르난드 초원 → 페일룬 설산 → 붉은사막 협곡 → 심연으로 이어집니다. 출발은 매번 처음부터이며 착지한 거리·수집 은화가 다음 강화의 재원이 됩니다.

- **물리 튜닝:** 화면 하단에서 중력 가속도·시작 높이·도약 속도·공기 저항·활강 각도/보정·상승/급강하 반응·스태미너 소모·대시 속도를 조절합니다. 적용하면 진행 중 비행의 보상 없이 출발 지점으로 돌아옵니다. 현재 강화 효과는 유지되며 튜닝 값에 추가 적용됩니다. 설정은 별도 `crimson-flight:tuning:v1` 키에 저장하고 기본값 복원도 지원합니다. 수직 속도는 양수가 상승, 음수가 하강입니다. 자동 활강 보정과 활강 저항을 0으로 두면 중력으로 낙하 속도가 계속 증가하는 것을 확인할 수 있습니다.
- **진행 초기화:** 하단 버튼을 누르고 확인하면 은화·모든 강화·최고 기록·누적 거리·비행 횟수가 0으로 돌아갑니다. 캐릭터와 튜닝 설정은 유지합니다.
- **캐릭터:** 비행 화면 위의 클리프·데미안 버튼으로 플레이할 캐릭터를 바꿀 수 있으며 외형만 다릅니다. 성능·은화·강화·기록은 공유하고 선택은 브라우저에 저장합니다.
- **도약:** 버튼을 눌렀다 놓아 힘을 정하거나 화면을 오른쪽 위로 드래그합니다. 각도 슬라이더는 15–75도이며 짧게 누르면 기본 힘으로 출발합니다.
- **글라이더 조작:** 손을 놓으면 날개를 편 채 완만하게 하강 활강합니다. ↓/S 또는 급강하 버튼으로 빠르게 내려가 속도를 모읍니다. ‘상승’ 또는 Space/↑/W를 누르면 스태미너를 소비해 비행 방향을 위로 돌리고, 속도를 높이로 바꿉니다. 하강 중 누르는 시점과 길이를 조절해 상승·하강을 반복하세요. 오래 누르면 감속해 상승할 힘을 잃습니다. 공기 저항으로 에너지를 잃으므로 보급·추진 없이 무한 상승할 수 없습니다. 캐릭터와 날개는 비행 각도와 조작에 맞춰 움직이며 고도·속도를 표시합니다.
- **섭리의 힘 대시:** 버튼 또는 Shift. 스태미너 24를 써서 속도·고도를 높이며 1.2초 재사용 대기가 있습니다. ↑/Space/W는 기수 들기, ↓/S 또는 모바일 급강하 버튼을 누르고 있으면 급강하합니다. 동시에 누르면 급강하가 우선하며 스태미너 없이도 가능합니다.
- **수집과 장애물:** 은화는 강화 비용, 야영 보급품은 스태미너 회복, 푸른 상승 기류는 속도·고도를 높입니다. 부유 유적에 부딪히면 감속하고 스태미너가 줄어듭니다.
- **야영지:** 지구력·힘의 도약·까마귀의 날개·섭리의 힘·심연의 인력·야영지 요리를 각각 5단계까지 강화합니다. 비행 중 구매할 수 없습니다.
- **일시정지:** Ⅱ/Esc. 다른 탭으로 이동하면 자동 일시정지하며 ‘계속 비행하기’로 재개합니다. 효과음은 기본 꺼짐입니다.
- **저장:** 은화·강화·최고 기록은 `crimson-flight:v1` localStorage에 저장됩니다. 브라우저/사이트 데이터를 삭제하면 사라지고 기기 간 공유되지 않습니다. 진행 중 비행 자체는 저장하지 않습니다.

[참고한 종이비행기 게임 소개](https://m.blog.naver.com/wishl2/221331196801)의 던지기 → 조종·수집 → 강화 → 재도전 구조를 참고했습니다. 세계와 인물의 분위기는 [붉은사막 공식 소개](https://crimsondesert.pearlabyss.com/ko-KR/Main/Index)를 참고했으며, 수치·강화 효과·코스는 이 팬 게임의 독자 규칙입니다. 공식 게임 화면/음원을 추출하지 않았습니다. [배경 그림과 생성 기록](web/assets/README.md).

## 알까기

화면 너비를 활용하는 나무 바둑판에서 흑돌 5개와 백돌 5개로 즐기는 턴 방식 터치 게임입니다. 돌은 M자 대형이며 가로 이음선과 중앙 연결쇠가 있습니다. `alkkagi.html`에서 직접 시작할 수 있습니다.

## 온라인 대전 배포

[Render에 배포하기](https://render.com/deploy?repo=https://github.com/south-hive/kick-go)

Render 계정에서 위 링크로 `render.yaml`을 적용하거나, Node.js 호스팅에 다음 설정으로 배포합니다.

- Build: `npm ci --omit=dev`
- Start: `npm start`
- Health check: `/health`
- 포트: 호스팅의 `PORT` 환경변수 사용, `0.0.0.0` 바인딩
- 웹소켓: 같은 호스트의 `/ws` 경로, HTTPS/WSS 필요

배포된 서버 주소 자체에서 게임과 온라인 대전이 모두 동작합니다. 기존 GitHub Pages에서도 접속하려면 저장소 Settings → Secrets and variables → Actions → Variables에 `KICK_GO_SERVER`를 서버의 HTTPS 주소로 등록하고 Pages 워크플로를 다시 실행하세요. 등록 전 Pages는 오프라인 모드를 제공하며 온라인 탭에 준비 중 안내를 표시합니다. API 키나 비밀 토큰을 이 변수에 넣지 않습니다.

### 플레이

1. ‘온라인 대전’ → ‘방 만들기’를 누르면 방장은 흑돌입니다.
2. ‘초대 링크 복사’로 공유한 링크에서 상대가 ‘입장’을 누르면 백돌로 참가합니다. 12자리 코드를 직접 입력해도 됩니다.
3. 각자 자기 차례에만 조작합니다. 돌의 충돌, 회전, 낙하, 승패는 서버에서 계산해 두 화면에 전달합니다.
4. 연결이 끊기면 새 샷은 잠기고 진행 중인 샷은 서버에서 마무리합니다. 같은 탭을 새로고침하거나 연결이 돌아오면 기존 자리와 판을 복구합니다.
5. 경기 종료 후 두 사람 모두 ‘재대결’을 눌러야 새 판이 시작됩니다. 한 사람이 명시적으로 나가면 방이 닫힙니다.

### 운영 범위

현재는 **서버 인스턴스 한 개**에서 방을 메모리에 보관합니다. 서버 재시작·재배포 때 기존 방이 종료됩니다. 10분간 접속이 끊긴 자리 또는 30분간 진행이 없는 방은 정리하며 최대 100개 방을 허용합니다. 재접속 정보는 같은 탭의 sessionStorage에 저장되어 탭을 닫으면 사라질 수 있습니다. 영구 저장·여러 서버 간 동기화·매칭·랭킹은 포함하지 않습니다. 무료 호스팅의 절전 정책에 따라 첫 접속이 지연될 수 있습니다.

기본 허용 웹 출처는 서버 자체 주소와 `https://south-hive.github.io`입니다. 다른 프런트엔드를 사용하면 `ALLOWED_ORIGINS`에 출처를 쉼표로 구분하여 지정하세요.

## 안드로이드 앱 빌드

Android Studio에서 `android` 폴더를 열고 Gradle 동기화 후 Run으로 설치하세요. JDK 17, Android SDK 35, Gradle 8.9가 필요합니다. Gradle wrapper 바이너리는 포함하지 않았습니다. Gradle 8.9가 설치되어 있으면 `android`에서 `gradle wrapper --gradle-version 8.9`로 생성한 후 `./gradlew assembleDebug`를 실행할 수 있습니다.

APK 출력: `android/app/build/outputs/apk/debug/app-debug.apk`

앱은 웹 게임 파일을 assets에 포함하는 Android WebView 앱입니다. 인터넷 권한 없이 오프라인으로 실행됩니다. 온라인 대전은 현재 웹 브라우저 버전을 사용하세요. Android 8.0 이상 및 최신 Android System WebView를 권장합니다. 화면은 세로 방향입니다. 알까기 경기 저장은 지원하지 않으며 비행 게임의 강화·기록은 WebView 저장소에 남습니다.

## 조작과 규칙

- 내 돌을 누르고 발사 반대 방향으로 당겼다가 놓습니다. 당긴 거리가 발사 강도를 결정합니다. 하드웨어 터치 압력은 사용하지 않습니다.
- 하단 타격점의 아래쪽은 백샷, 위쪽은 전진, 좌우는 발사 방향 기준 옆 회전입니다. 중심에서 멀수록 강하며, 대각선 조합도 가능합니다. 상대 돌과 처음 충돌할 때 저장된 회전을 적용하는 게임식 물리 효과이며, 이동 중 회전은 서서히 줄어듭니다. 매 턴 중앙으로 초기화됩니다. 방향키와 Home 키로도 조절할 수 있습니다.
- 돌끼리 탄성계수는 0.84이며, 저속에서는 마찰을 강화해 잔여 미끄러짐을 줄입니다. 화면 가장자리에 가까우면 당김에 필요한 거리를 줄여 최대 힘을 낼 수 있습니다.
- 조준 화살표와 하단 힘 표시를 확인할 수 있습니다. 거의 당기지 않고 놓으면 취소됩니다.
- 모든 돌이 멈추면 다음 차례로 넘어갑니다. 판 중앙 좌우의 금속 연결쇠 두 개는 고정 장애물입니다.
- 돌 중심이 판 가장자리를 넘으면 탈락합니다. 상대 돌을 모두 떨어뜨리면 승리하며 양쪽 마지막 돌이 함께 탈락하면 무승부입니다.
- 혼자 하기: 흑돌을 조작하고 백돌 AI와 대결합니다. 둘이 하기: 같은 화면에서 흑/백을 번갈아 조작합니다.
- 우측 상단 음표로 효과음을 켜거나 끕니다. 기본은 꺼짐입니다.

## 검증

`npm test`로 알까기 물리/온라인 통신과 비행 궤적·스태미너·수집·강화·보상 중복 방지·저장 데이터 복구를 검증합니다. `npx playwright install chromium` 후 `npm run test:browser`로 게임 선택·비행/착지/강화·휴대폰/데스크톱 배치와 알까기의 실제 공방·새로고침 복구·타격점 UI를 검증합니다. GitHub Actions에서는 Chromium 설치를 자동으로 수행합니다. 실제 Android 빌드와 기기 터치 검증은 별도로 필요합니다.

데미안의 2D 외형은 [펄어비스 공식 홍보 이미지](https://s1.pearlcdn.com/cd/brand/media_GLOBAL/2025/03/19/387b0ae6ee220250319043154727.jpg)의 긴 흑발·땋은 머리·금장 은빛 갑옷을 참고한 생성 일러스트로 교체했습니다. 대기·비행 자세와 얼굴 미리보기를 사용하며, 비행 각도와 날개는 Canvas에서 실시간으로 움직입니다.
